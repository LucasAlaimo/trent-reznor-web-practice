# Trent Reznor — Web Development Practice

## About the Project

This project is a tribute website dedicated to Trent Reznor, developed as an academic frontend web development exercise.

The website features an industrial and minimalist design inspired by the artist's visual identity. It was built to practice web layout techniques, responsive design, code organization, and interactive functionality using fundamental web technologies.

## Technologies Used

- **HTML5** — Semantic structure and content.
- **SCSS (Sass)** — Modular styling, variables, and nested selectors, compiled into CSS.
- **CSS3** — Grid, Flexbox, media queries, animations, and custom properties.
- **Vanilla JavaScript** — DOM manipulation, event handling, and interactive components.

## Features

- Responsive layouts for desktop and mobile devices.
- Dark/Light Mode with preferences saved using `localStorage`.
- Sticky desktop navigation and a sliding mobile navigation menu.
- Interactive album carousel with navigation controls and hover effects.
- Downloadable PDF with technical project documentation.

## Development Process

The project was developed through three iterations:

1. **Structure and Design:** HTML structure, content, and initial SCSS styling.
2. **Interactivity:** Theme switching, navigation improvements, and album carousel.
3. **Responsive Design and Finalization:** Mobile adaptations, testing, and documentation.
